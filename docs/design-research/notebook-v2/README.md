# Revised notebook motion

The first flow scattered sheets and changed text independently of the artwork. This revision uses one reversible scroll timeline with three coordinated page handoffs.

| Progress | Motion |
| --- | --- |
| 0-12% | Intro reading hold |
| 12-30% | Gather the fan and reveal Build |
| 30-43% | Build reading hold |
| 43-61% | Turn the Layla sheet and reveal Explore |
| 61-74% | Explore reading hold |
| 74-92% | Turn the Qeemat sheet and reveal Write |
| 92-100% | Write reading hold and natural release into the page |

Copy exits and enters within these same transition windows. Paper layering is fixed; the chapter rail shows continuous progress. A short time-based damping pass smooths wheel increments without intercepting scrolling, and stops requesting frames once settled.

The PNGs are actual production-browser captures. `desktop-flow.png` is a contact sheet of the three chapter compositions, not a recording. Review the live local preview for timing and feel. See the motion revision section in [design-qa.md](../../../design-qa.md) for verification.
